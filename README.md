# Dragon Ball Fan Site

Site fan-made sobre o universo de Dragon Ball, desenvolvido com HTML, CSS e JavaScript. O projeto exibe uma página inicial com história, personagens, mangás, filmes, músicas e links para páginas complementares.

## 🔗 Link do projeto

- GitHub Pages: https://viniciusblesa.github.io/Site-Dragon-Ball/

## 📌 Visão geral

Este projeto foi criado como uma página temática de Dragon Ball para apresentar:

- história da franquia
- enredo e sagas principais
- personagens favoritos
- mangás
- filmes
- músicas e aberturas
- navegação entre páginas internas
- interação com elementos visuais e menu responsivo

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages para deploy
- Imagens locais e vídeos locais

## 🖥️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/Site-Dragon-Ball.git
```

2. Acesse a pasta do projeto:

```bash
cd Site-Dragon-Ball
```

3. Inicie um servidor local:

```bash
python -m http.server 8000
```

4. Abra no navegador:

```text
http://localhost:8000
```
